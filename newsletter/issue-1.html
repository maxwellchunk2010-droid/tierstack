Patch Notes: week of Oct 19–23, 2026

Firebase Studio drops to C, Muse Code and Amp join, and the releases worth knowing. Published 2026-10-28.

All placements are editorial (v0) while hands-on testing is in progress. Paying never changes a tier.

Tier changes (and why)

  • Firebase Studio: B → C. It closed to new signups and workspaces on 2026-06-22 and shuts down on 2027-03-22 (Firebase docs, rechecked Oct 21). New users should pick another builder.
  • New: Muse Code (Meta) at B. Plans are $5/$15/$50/$200. Contributor mode is on by default, meaning Meta trains on your content unless you turn it off. Source.
  • New: Amp at B. Free Hobby tier with your own subs/keys, $20 Individual, and a new Linear agent (Oct 19). B is our standard untested starting placement for new listings. Source.

New releases worth knowing

  • Claude Code 2.1.304–2.1.307. 2.1.307 stops HTTP MCP tool calls from being sent twice when a connection drops. Matters if your agent writes to databases, payments or tickets through MCP. Changelog.
  • VS Code 1.143. The Copilot harness is now the default, plus a Compare Models view. Release notes. Copilot CLI 1.0.100 also shipped (release).
  • Amp in Linear. Assign issues to an agent from Linear. Amp news.
  • Recursive Flint. An open-weight (Apache 2.0) coding model built to run locally on a laptop; benchmarks are vendor-reported. Announcement.
  • MiniMax M3.1 Flash at $0.15 in / $0.60 out per million tokens. Cheap fuel for bring-your-own-key agents. MiniMax blog.
  • OpenAI models are coming to Google Cloud Model Garden (GA planned in the coming weeks), and soon to Google Antigravity. OpenAI post.
  • Framer MCP. An official MCP server lets Codex, Claude Code, Cursor and others edit and publish Framer sites. Framer updates.
  • Meta Muse Spark Open and new Muse plans also landed. Meta blog.

One pick per job

  • Daily AI coding in an editor: Cursor.
  • Terminal, whole-repo agent work: Claude Code (comes with Claude Pro).
  • Hand off scoped tasks to a cloud agent: OpenAI Codex.
  • Coding agent on $10/month: GitHub Copilot Pro.
  • Idea to full-stack app by prompting: Lovable.
  • Polished UI on a Next.js stack: v0.
  • Backend (Postgres, auth, storage): Supabase.
  • Deploying a frontend: Vercel.
  • Workflow automation you can self-host: n8n.
