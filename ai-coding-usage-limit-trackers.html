How to track AI coding usage limits (Claude Code, Codex, Copilot)

The built-in commands and the free, open-source trackers that show how much of your Claude Code, Codex or Copilot allowance you have left, plus what to switch to if Claude Code is down or you hit a limit. Trackers below were checked 2026-10-28. The switch-to notes and Nov 13 outage dates were checked 2026-11-17.

Editorial guide, not test scores. We list tools, we don't rank them, and nobody paid to be here. Third-party trackers are community projects: read what they access before you sign in.

Claude Code is down, or you hit a usage limit. What should you switch to?

First check whether the service is actually down on status.claude.com. If you still have access, Claude Code’s /usage command shows plan bars and the rolling “5-hour limit.”

On Nov 13, 2026, Anthropic’s status page recorded two major incidents that affected Claude Code. The first, opened at 09:58 UTC, involved authentication issues on claude.ai and Claude Code and was marked resolved at 11:58 UTC. The second, opened at 13:09 UTC, involved elevated errors on claude.ai, the Claude API, and Claude Code and was marked resolved at 15:38 UTC. Those incidents are closed. As of Nov 17, 2026, Claude Code and the Claude API were listed as operational. Always check the live status page; do not assume an older incident is still happening.

If Claude Code is unavailable, or you have hit a usage limit and need to keep working, these are the other coding agents already on TierStack. This is an editorial switch list, not a claim that any of them was unaffected or is “better” because of an outage. Check each vendor’s own status page and official pricing.

  • Cursor — an AI-first editor. S tier in our editorial v0 coding-agents list. Official site: cursor.com.
  • OpenAI Codex — the Codex CLI and ChatGPT coding agent. Use /status in the CLI to see remaining usage. A tier (editorial v0). Official pricing and limits: ChatGPT pricing.
  • GitHub Copilot — usage for premium requests is in your GitHub billing settings. A tier (editorial v0). GitHub docs.

A practical habit is to keep two agents from different vendors ready and route by task, so a limit or an outage on one does not stop the work. For plan facts and a pick per job, see Cursor vs Claude Code vs Codex and Best AI coding agent on a budget.

Start with the built-in commands

  • Claude Code: /usage. Pro and Max subscribers see plan usage bars, activity stats and a usage breakdown. Since 2.1.312 the rolling window is called the “5-hour limit”. Claude Code docs.
  • OpenAI Codex: /status. Shows remaining usage in the CLI. Limits depend on your ChatGPT plan and model. Codex pricing & limits.
  • GitHub Copilot: premium request usage is shown in your GitHub billing settings. GitHub docs.

Free trackers worth knowing

Terminal · any OS

ccusage

Reads the local logs coding CLIs already write and reports daily, weekly, monthly and per-session tokens and estimated cost. Covers Claude Code, Codex, Amp, Copilot CLI, Gemini CLI, Antigravity and more, plus Claude 5-hour blocks. Run npx ccusage@latest. It estimates usage from logs; it does not read your plan's limit.

macOS menu bar

AgentLimits

Menu bar app and widgets showing Codex and Claude Code 5-hour and weekly usage plus Copilot premium requests. Marked “in development”; it signs in to your accounts and uses unofficial endpoints.

Windows 11 tray

OpenTokenUsage

Free, open-source (MIT) tray app showing session and weekly limits, credits and reset times for Claude, Codex, Cursor and other subscriptions.

Terminal + tray · Linux/macOS/Windows

aiusage

Shows Claude session (5h) and weekly usage via your existing Claude Code login, Codex weekly limits if the CLI is installed, and a local spend estimate. Exposes a loopback-only JSON API.

How to stop hitting limits

  • Check usage before a big multi-file task, not after.
  • Keep context lean: trim large CLAUDE.md/AGENTS.md files and unused MCP servers.
  • Use smaller models for routine edits.
  • Run two agents from different vendors and route by task. See Best AI coding agent on a budget and Cursor vs Claude Code vs Codex.
