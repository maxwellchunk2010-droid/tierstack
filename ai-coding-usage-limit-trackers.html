How to track AI coding usage limits (Claude Code, Codex, Copilot)

The built-in commands and the free, open-source trackers that show how much of your Claude Code, Codex or Copilot allowance you have left. Every tool below links to its official page or repo, checked 2026-10-28.

Editorial guide, not test scores. We list tools, we don't rank them, and nobody paid to be here. Third-party trackers are community projects: read what they access before you sign in.

Start with the built-in commands

  • Claude Code: /usage. Pro and Max subscribers see plan usage bars, activity stats and a usage breakdown. Since 2.1.312 the rolling window is called the “5-hour limit”. Claude Code docs.
  • OpenAI Codex: /status. Shows remaining usage in the CLI. Limits depend on your ChatGPT plan and model. Codex pricing & limits.
  • GitHub Copilot: premium request usage is shown in your GitHub billing settings. GitHub docs.

Free trackers worth knowing

Terminal · any OS

ccusage

Reads the local logs coding CLIs already write and reports daily, weekly, monthly and per-session tokens and estimated cost. Covers Claude Code, Codex, Amp, Copilot CLI, Gemini CLI, Antigravity and more, plus Claude 5-hour blocks. Run npx ccusage@latest. It estimates usage from logs; it does not read your plan's limit.

macOS menu bar

AgentLimits

Menu bar app and widgets showing Codex and Claude Code 5-hour and weekly usage plus Copilot premium requests. Marked “in development”; it signs in to your accounts and uses unofficial endpoints.

Windows 11 tray

OpenTokenUsage

Free, open-source (MIT) tray app showing session and weekly limits, credits and reset times for Claude, Codex, Cursor and other subscriptions.

Terminal + tray · Linux/macOS/Windows

aiusage

Shows Claude session (5h) and weekly usage via your existing Claude Code login, Codex weekly limits if the CLI is installed, and a local spend estimate. Exposes a loopback-only JSON API.

How to stop hitting limits

  • Check usage before a big multi-file task, not after.
  • Keep context lean: trim large CLAUDE.md/AGENTS.md files and unused MCP servers.
  • Use smaller models for routine edits.
  • Run two agents from different vendors and route by task. See Best AI coding agent on a budget and Cursor vs Claude Code vs Codex.
